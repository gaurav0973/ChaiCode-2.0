# TypeScript Learning Roadmap

This document organizes the TypeScript topics into clear phases so you can learn in a practical order.

## Learning Goals

- Understand why TypeScript is used in modern JavaScript projects.
- Build confidence with core and advanced types.
- Learn patterns used in production codebases.
- Apply TypeScript with Node.js, Express, and React.

## Roadmap Overview

| Phase | Focus          | Outcome                                    |
| ----- | -------------- | ------------------------------------------ |
| 1     | Core Types     | Write safe, predictable TypeScript basics  |
| 2     | Code Structure | Model real-world data and APIs cleanly     |
| 3     | Advanced Types | Use TypeScript power features effectively  |
| 4     | Industry Usage | Build production-ready TypeScript projects |

## Phase 1: TypeScript Foundations (Core Types)

**Goal:** Understand why TypeScript exists and how types work.

### Topics

- Why TypeScript exists
- Type annotations
- Type inference
- Primitive types
  - `string`
  - `number`
  - `boolean`
- Arrays and object typing
- Function typing
- Optional parameters
- Default parameters
- Union types
- Literal types
- Type aliases
- `any`, `unknown`, `never`
- Type assertions
- Enums

**Industry relevance:** Makes JavaScript code more predictable and safer.

## Phase 2: Structuring Real Code

**Goal:** Build clean, scalable code.

### Topics

- Interfaces
- Interfaces vs type aliases
- Function interfaces
- Object interfaces
- Optional properties
- Readonly properties
- Extending interfaces
- Intersection types

**Industry relevance:** Useful for API contracts and data modeling.

## Phase 3: Advanced Type System

**Goal:** Understand TypeScript power features.

### Topics

- Generics
- Generic functions
- Generic interfaces
- Generic constraints
- Utility types
  - `Partial`
  - `Pick`
  - `Omit`
  - `Record`
  - `Required`
- `keyof`
- `typeof`
- Mapped types
- Conditional types
- Discriminated unions

**Industry relevance:** Essential for large-scale applications.

## Phase 4: Real Industry Usage

**Goal:** Use TypeScript the way real companies do.

### Topics

- Modules
- TypeScript with Node.js
- TypeScript with Express
- TypeScript with React
- `tsconfig` deep dive
- Declaration files
- Third-party types
- Strict mode
- Error handling patterns
- Project structure

**Industry relevance:** Helps build and maintain production apps.

## Suggested Learning Flow

1. Complete each phase in order.
2. Build a mini project after each phase.
3. Revisit Phase 3 while working on Phase 4 projects.
